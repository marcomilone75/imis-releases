# IMIS 2.0 — Releases

Binari di distribuzione dell'app desktop **IMIS 2.0** (Integrated Management Information System) per **Fantasia Diamonds Creations Ltd**.

Questa repository contiene solo i binari installabili. Il codice sorgente è in [marcomilone75/imis](https://github.com/marcomilone75/imis) (repository privata).

## Download

Scarica l'ultima versione dal tab **[Releases](https://github.com/marcomilone75/imis-releases/releases/latest)**, scegliendo il file adatto al tuo sistema operativo:

| Sistema | File |
|---|---|
| **Windows** (installer) | `IMIS-Setup-x.y.z.exe` |
| **Windows** (portable) | `IMIS-Portable-x.y.z.exe` |
| **Linux** (AppImage, universale) | `IMIS-x.y.z.AppImage` |
| **Linux** (Debian / Ubuntu) | `IMIS-x.y.z.deb` |
| **macOS** (Intel) | `IMIS-x.y.z-x64.zip` |
| **macOS** (Apple Silicon) | `IMIS-x.y.z-arm64.zip` |

## Auto-update

L'applicazione, una volta installata, controlla automaticamente la disponibilità di aggiornamenti ad ogni avvio. Non è necessario scaricare manualmente le nuove versioni.

## Come vengono pubblicati i binari

I binari vengono generati e pubblicati **automaticamente** tramite GitHub Actions ogni volta che nella repository di sviluppo viene creato un tag nel formato `v*` (es. `v0.1.0`, `v1.2.3`).
